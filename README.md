# Для начала работы необходимо скопировать себе весь репозиторий и перейти в папку с проектом
**Прописать команду**
```bash
docker-compose up -d
```

**В браузере открыть страницу http://localhost:8000**
*в ответ будет получена связка ip : your_ip_address*

### Для передачи имени hostname нужно использовать query params
**Ссылка в таком случае будет выглядеть: http:\/\/localhost:8000/?hostname=$your_hostname**
*В ответ будет получено подтверждение привязки hostname : ip на время TTL, задаваемое в файле methods.py*

### Для получения информации о сохраненном за hostname ip-адресе необходимо использовать ссылку http:\/\/localhost:8000/lookup/$your_hostname
**В ответ будет получен hostname : ip**
*В случае отсутствия в памяти соответствущего hostname будет получен код 404*

# Для запуска тестов необходимо использовать команду
```bash
docker compose run sber_test_app pytest tests/test_main.py
```
**Она запустит отдельный контейнер и прогонит в нем тесты, удалив контейнер по окончанию**
